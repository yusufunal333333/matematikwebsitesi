
# Architecture Overview

## Language Notice
This document is written in English for developers.
THE WEBSITE CONTENT MUST BE IN TURKISH.

## Application Architecture
The application uses a simple server-side rendered architecture:
- Express for routing
- EJS for HTML rendering
- Static assets served via Express

## Design Principles
- Simplicity
- Readability
- Educational clarity
- No unnecessary complexity

## Folder Responsibilities
- /views → Turkish EJS templates
- /public/css → Stylesheets
- /public/images → Images
- app.js → Routing and logic
