# Development Rules

## Language Rule
- Website output language: Turkish only
- Documentation language: English
- Code comments: English allowed

## Coding Rules
- Use modern JavaScript
- Prefer clarity over optimization
- Avoid deeply nested logic

## HTML & CSS Rules
- Use semantic HTML
- No inline styles
- No CSS frameworks

## Educational Rules
- Content must be clear and understandable
- Avoid unnecessary jargon
- Suitable for middle school students
