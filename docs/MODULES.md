# Application Modules

## IMPORTANT
All modules must generate TURKISH content on the website.

## 1. Mathematics Introduction Module
Title:
- Matematik Nedir?

Requirements:
- At least one full page of Turkish text
- Explain what mathematics is
- Explain where mathematics is used
- Include images

## 2. Famous Mathematicians Module
Title:
- Ünlü Matematikçiler

Requirements:
- List page
- Individual profile pages
- Large image per mathematician
- Minimum one page detailed biography (Turkish)

## 3. Career Guidance Module
Title:
- Matematikçi Olmak İçin Neler Yapılmalıdır?

Requirements:
- Long-form Turkish content
- Motivational and educational tone
- Images included

## 4. Quiz Module
Requirements:
- Exactly 20 questions
- Turkish questions and answers
- Mixed difficulty (basic, numerical, logic)
- Answer options must be shuffled
