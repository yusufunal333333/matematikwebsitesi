# GitHub Copilot Instructions – Mathematics World Project

## 🚨 CRITICAL LANGUAGE RULE (DO NOT IGNORE)
ALL WEBSITE CONTENT MUST BE IN TURKISH.
This includes:
- Page titles
- Paragraphs
- Headings
- Lists
- Quiz questions and answers

English is allowed ONLY in source code comments and Markdown documentation files.

## Project Overview
This is an educational Mathematics web application for middle school students in Turkey.
The website language is Turkish, and the content must be age-appropriate and educational.

## Technology Stack
- Node.js
- Express.js
- EJS templating
- Plain CSS (no frameworks)

## Mandatory Pages (ALL IN TURKISH)
1. Matematik Nedir?
2. Ünlü Matematikçiler
   - List page
   - Detailed profile pages (minimum one full page text each)
3. Matematikçi Olmak İçin Neler Yapılmalıdır?
4. Quiz

## Quiz Rules
- EXACTLY 20 questions
- Questions and answers must be in Turkish
- Include numerical and logical reasoning questions
- Shuffle answer options on every render
- Correct answer must NOT always be the first option

## Content Rules
- Long-form educational content (minimum one page per informational page)
- No placeholder text
- Images must be referenced in pages

## Styling Rules
- Base font size: 10pt
- Main titles:
  - At the top of the page
  - Bold
  - Larger than body text

## Forbidden
- No database usage
- No authentication systems
- No frontend frameworks
